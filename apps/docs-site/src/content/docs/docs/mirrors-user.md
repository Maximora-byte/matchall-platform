title: Mirrors 下载与授权
description: 校验下载、Release Channel、CDK 与更新 Token。
lastUpdated: 2026-08-30
---
每个制品会显示平台、架构、大小和 SHA-256。下载后建议校验哈希。

- **stable**：适合生产环境。
- **beta**：包含即将发布的功能。
- **alpha**：早期测试。

付费项目可通过订单或 CDK 获得访问权；自动更新程序应使用可撤销的更新 Token。
