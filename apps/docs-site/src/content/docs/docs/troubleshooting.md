---
title: 常见问题排查
description: 登录、同步、下载和状态异常的安全排查顺序。
lastUpdated: 2026-08-30
---
1. 先查看 `https://status.maximoraverse.org/`。
2. 确认系统时间准确，浏览器未阻止 Cookie。
3. 使用隐私窗口排除旧缓存和扩展影响。
4. 重新从官方主页进入服务，不复用旧回调链接。
5. 下载问题请记录项目、版本、平台、架构和错误时间，但不要提交 Token。

仍无法解决时，通过统一账户主页的联系方式提交问题。
