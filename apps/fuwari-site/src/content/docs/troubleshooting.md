排查的目标是先判断“服务故障、账户问题、设备问题还是本地网络问题”，再做最小变更。不要一开始就清空全部数据或重装客户端。

## 通用五步

1. 查看 [Status](https://status.maximoraverse.org/) 是否有维护或故障；
2. 记录发生时间、服务、操作和错误提示；
3. 确认系统时间准确、网络没有频繁切换；
4. 使用隐私窗口排除旧 Cookie 和扩展影响；
5. 从官方主页重新进入，不复用旧回调或带签名 URL。

## 登录问题

若出现循环跳转、验证码失败或登录后仍显示未登录：

- 允许 Account 与目标服务使用 Cookie；
- 暂停内容拦截和脚本修改扩展；
- 清除这两个站点的 Cookie 后重试；
- 不要收藏 OIDC 回调页；
- 检查账户是否锁定或邮箱是否待验证。

## Drive 同步问题

先暂停同步，确认磁盘空间、文件占用和路径长度。查看客户端活动记录，判断是单个文件还是整个账户失败。冲突文件先保留，不要批量删除。DAV 返回 401 通常表示认证失败，不等同于服务器离线。

## Network 连接问题

刷新订阅并切换备用线路，比较不同网络环境。检查是否同时运行多个 VPN、系统代理或安全软件。提交日志前删除订阅 URL、节点 URI、IP 和设备令牌。

## Mirrors 下载问题

确认授权、版本、系统和架构。记录 HTTP 状态码，并重新计算 SHA-256。401/403 多为授权问题，404 可能是版本撤回或链接过期，5xx 才更可能是服务端异常。

## 浏览器显示旧页面

先普通刷新，再关闭标签页重新打开。仍异常时可清除该站点缓存，但不要无差别清空密码和全部浏览数据。若只有一台设备异常，优先检查 Service Worker、扩展和系统主题缓存。

## 提交有效的问题报告

请提供：

- 服务名称和页面地址；
- 发生时间及所在时区；
- 操作系统、浏览器或客户端版本；
- 可复现步骤；
- HTTP 状态码或经过脱敏的错误信息；
- 是否在其他网络或设备复现。

不要提供密码、验证码、恢复代码、订阅、Token、Cookie、私有下载 URL 或包含这些信息的截图。能够复现的问题比“不能用”更容易快速定位。
