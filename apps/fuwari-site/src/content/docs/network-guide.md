MatchAll Network 为已开通用户提供线路、订阅和设备管理。订阅地址与设备令牌等同于访问凭据，任何拿到它的人都可能消耗你的流量。

## 获取配置

1. 打开 [Network](https://proxyservice.maximoraverse.org/) 并登录；
2. 进入服务中心，确认套餐和到期时间；
3. 按客户端类型复制订阅或使用页面提供的导入方式；
4. 回到客户端刷新配置，确认节点列表出现；
5. 先用普通网页完成连通性测试。

不要把完整订阅地址粘贴到测速网站、公开 Issue、群聊或截图中。怀疑泄露时应在账户页面重置，而不是只删除消息。

## 选择线路

不要只看一次测速峰值。更可靠的判断顺序是：

1. 连续延迟和抖动；
2. 丢包和连接失败率；
3. 常用网站的 TCP/TLS 建连与首字节时间；
4. 最后才是大文件吞吐量。

移动网络、家庭宽带和公司网络的最佳线路可能不同。视频、网页和软件更新也可能适合不同线路。建议保留一个稳定备用节点。

## 更新与设备管理

- 客户端应定期刷新订阅，但不要设置异常高频率；
- 更换手机或重装系统后，清理不再使用的旧设备；
- 套餐、流量、设备数和到期时间以账户页显示为准；
- 节点临时消失时先刷新订阅并查看 Status，不要反复重新导入。

## 常见故障

**所有线路都连接失败**：先关闭并重新开启客户端核心，确认系统时间、网络和订阅是否有效，再查看 [Status](https://status.maximoraverse.org/)。

**只有一个节点失败**：切换备用节点并记录节点名、运营商、发生时间和错误类型；不要提交节点 URI。

**延迟正常但网页慢**：比较 DNS、TCP/TLS 与 TTFB，关闭可能冲突的系统代理、VPN 或安全软件后复测。

**订阅刷新失败**：确认账户未过期、设备数未超限，重新从账户页复制订阅。不要手工修改 Token。

**移动网络可用、Wi-Fi 不可用**：可能是本地网络、IPv6、MTU 或防火墙差异。重启路由器并切换备用协议后再判断。

## 提交问题时提供

- 客户端名称和版本；
- 操作系统版本；
- 网络类型和运营商；
- 出错时间与节点显示名称；
- 不含订阅、Token、IP 和个人信息的错误日志。
