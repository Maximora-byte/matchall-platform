IPv4 / IPv6 双栈服务器

账号专属 DoH 地址的主机名同时发布 A 和 AAAA。通常只需填写上方完整地址，系统会按当前网络自动选择 IPv4 或 IPv6。

这两个 IP 仅用于需要手工填写“DNS 服务器 IP”的系统界面；DoH 模板仍必须使用上方带令牌的完整 HTTPS 地址。不要把 URL 中的主机名替换成 IP，也不要把裸 IP 当作账号入口。

iPhone / iPad / Mac

用 Safari 登录本站并下载描述文件，再到系统设置完成安装。描述文件同时包含 IPv4 和 IPv6 服务器，系统会选择当前网络可用的地址。所有设备可使用同一份配置。

下载 Apple 描述文件 ↓

设置 → 通用 → VPN 与设备管理 → 已下载的描述文件。文件未签名，仅包含 DNS 设置，不包含根证书、VPN 或 MDM。可随时删除。

Windows 11

  1. 设置 → 网络和 Internet → 当前 Wi-Fi / 以太网 → DNS 服务器分配 → 编辑。
  2. 在 IPv4 中填写首选 DNS：{{ dns_ipv4 }}。
  3. 在 IPv6 中填写首选 DNS：{{ dns_ipv6 }}；当前网络没有 IPv6 时可暂不填写。
  4. IPv4 和 IPv6 的 DNS over HTTPS 都选择“开（手动模板）”，模板均填写上方同一个账号专属 DoH 地址。
  5. 关闭“失败时使用未加密请求”，保存。

IPv4 和 IPv6 共用同一令牌、过滤策略和统计，不是两个账号。不要把旧公共 DNS 填为备用，否则可能绕过此令牌的控制与统计。

Chrome / Edge / Firefox

浏览器设置 → 隐私与安全 → 安全 DNS / DNS over HTTPS → 自定义，将上方专属地址粘贴进去。

浏览器设置仅保护该浏览器。Android 原生私人 DNS 不支持此 DoH 链接，可用支持自定义 DoH 的客户端。

重新生成账号令牌

仅在链接泄露或需要换密钥时使用。重置后旧令牌立即失效，所有设备都需要更新地址或重新下载描述文件。请勿将地址分享给其他人。
