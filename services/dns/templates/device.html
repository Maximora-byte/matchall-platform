专属 DoH 地址

256 位随机令牌 · 60 QPS · 撤销后新查询立即拒绝

iPhone / iPad / Mac

用 Safari 登录本站，下载描述文件，再到系统设置完成安装。已有 DNS 描述文件时，选择需要启用的配置。

下载 Apple 描述文件 ↓

设置 → 通用 → VPN 与设备管理 → 已下载的描述文件。文件未签名，仅包含 DNS 设置，不包含根证书、VPN 或 MDM。可随时删除。

Windows 11

  1. 设置 → 网络和 Internet → 当前 Wi-Fi / 以太网 → DNS 服务器分配 → 编辑。
  2. 手动设置 IPv4 DNS：64.110.101.75。
  3. DNS over HTTPS 选择“开（手动模板）”，填写上方专属地址。
  4. 关闭“失败时使用未加密请求”，保存。

此地址是新令牌入口，后端自动选择解析节点。不要把旧公共 DNS 填为备用，否则会绕过此令牌的控制与统计。

Chrome / Edge / Firefox

浏览器设置 → 隐私与安全 → 安全 DNS / DNS over HTTPS → 自定义，将上方专属地址粘贴进去。

浏览器设置仅保护该浏览器。Firefox 可选择“最大保护”；不同浏览器的回退行为有所不同。

撤销这台设备

撤销后，此链接和描述文件不能再用于新查询。已经建立的网站连接或缓存不一定立即断开。你可以重新创建设备获取新令牌。
