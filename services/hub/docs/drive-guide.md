# Drive 同步与分享指南

登录 `https://drive.maximoraverse.org/` 后可使用网页文件管理。桌面端与移动端请添加同一服务器地址，并在浏览器完成 MatchAll 统一认证。

- 为公开链接设置到期时间和访问密码。
- 敏感文件不要使用永久公开链接。
- 分享结束后及时撤销链接。

WebDAV 与 CalDAV 地址会由服务器的 `.well-known` 路径自动引导。
