# MatchAll 快速开始

1. 在 **MatchAll Account** 创建或登录账户。
2. 打开 **Console**，确认账户已关联。
3. 按需进入 Drive、Network 或 Mirrors。
4. 在 **Status** 查看实时服务状态。

只从 `*.maximoraverse.org` 官方域名登录。工作人员不会索要密码、验证码或恢复代码。

> English: One MatchAll account connects Drive, Network, Mirrors and Console.

> 日本語: 一つの MatchAll アカウントですべてのサービスを利用できます。
