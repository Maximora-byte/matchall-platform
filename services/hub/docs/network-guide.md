# Network 客户端与线路选择

在 Network 账户页面获取客户端配置。不要公开分享订阅、节点 URI 或设备令牌。

- 优先使用延迟稳定、丢包较低的线路，而不是只看单次测速峰值。
- 移动网络和家庭宽带的最佳线路可能不同。
- 遇到连接问题时先查看 Status，再切换备用线路。

流量、设备数和到期时间可在 Console 与 Network 账户页面查看。
