# 通知投递与订阅偏好

通知中心始终保存站内副本。登录后可选择浏览器 Web Push；管理员配置 SMTP 后，具有已验证邮箱的账户还可开启邮件。

- 服务故障/恢复与版本发布会自动进入投递队列。
- 管理员公告默认只进入站内；只有显式确认时才外发。
- 暂时失败会指数退避重试，最多五次，并保留投递状态。
- 公开公告同时提供 RSS，不需要登录或浏览器权限。
- 取消偏好只影响后续通知，不删除站内历史。

浏览器通知需要 HTTPS、通知权限和 Service Worker。清理浏览器站点数据后需重新授权。
