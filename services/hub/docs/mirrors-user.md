[MatchAll Mirrors](https://mirrors.maximoraverse.org/) 提供软件项目、版本和多平台制品。公开项目可以直接浏览；私有项目需要团队成员权限，公开付费项目的下载需要有效授权。公开或私有是可见性设置，免费或付费是另一项访问设置。

## 找到正确制品

进入项目页后依次确认：

1. 项目名称、项目主页与许可证；
2. 版本号与发布时间；
3. 操作系统；
4. CPU 架构，例如 x86_64、arm64；
5. 文件类型、大小和可用的 SHA-256。

不要只凭文件名判断架构。下载错误架构通常会表现为无法启动或“格式不正确”。外部文件可能没有登记大小或哈希，页面会显示“外部文件”或“由上游提供”，应另向项目提供方确认。

## Release Channel

- **stable**：通常用于正式版本；
- **beta**：通常用于测试即将发布的功能，可能仍有兼容性问题；
- **alpha**：通常用于早期测试，仅用于评估，不建议承载重要数据。

通道由项目发布者选择，名称本身不保证软件经过平台验证或适合你的环境。先阅读发布说明；从 alpha 或 beta 切回 stable 前确认数据格式是否向后兼容。重要环境升级前应保留配置和数据备份。

## 校验下载

托管上传的 SHA-256 由服务端计算；外链制品的哈希由发布者填写。下载完成后使用系统工具计算哈希，并与项目页的值逐字符比较。匹配说明文件与该哈希一致，不等于平台已验证发布者身份或软件安全性。

Linux：

```bash
sha256sum <文件名>
```

macOS：

```bash
shasum -a 256 <文件名>
```

Windows PowerShell：

```powershell
Get-FileHash <文件名> -Algorithm SHA256
```

哈希不一致时不要运行文件，应删除并重新下载；再次失败时记录项目、版本、文件名和时间。

## 授权、CDK 与更新 Token

在[软件账户页](https://mirrors.maximoraverse.org/account)管理订单、CDK、授权和更新 Token。付费项目可通过对应商品的已确认订单或有效 CDK 获得访问权；提交订单或返回支付页面不代表授权已经生效，应核对账户页的订单与有效授权。

CDK 的总使用次数和到期时间由管理员配置，同一账户不能重复兑换同一码。请在已登录正确账户后操作。购买或兑换商品不会自动使你成为私有项目的团队成员。

自动更新程序应使用专用、可撤销的更新 Token，而不是账户密码。Token 仅在创建时完整显示一次，访问权仍取决于该账户的团队权限或有效授权。

- 不把 Token 写进公开仓库、镜像或日志；
- 每个环境使用独立 Token，便于撤销；
- 设备淘汰或 CI 停用后立即撤销；
- 收到 401/403 时先检查授权和到期状态，不要高频重试。

## 自动更新与下载链接

更新检查使用 `GET /api/v1/projects/{slug}/latest`，可按项目要求传入 `channel`、`system`、`arch` 和当前版本 `current`。登录身份对应的更新 Token 使用 `Authorization: Bearer mat_…` 请求头；不要把 Token 放进查询参数或公开分享。

私有项目和付费项目的客户端，应在更新检查以及返回的 Mirrors 机器下载地址上保留该请求头。返回地址中的短期 `token` 用于验证下载请求，不代替账户权限。后续跳转到对象存储时，不要向其他域名转发 Mirrors 的 Bearer Token。

项目可为更新 API 设置灰度比例。客户端使用稳定、随机生成且不含个人信息的 `client_id` 参与灰度；未提供该值时只会匹配 100% 发布的版本。灰度不限制有权限用户在项目页直接下载已发布制品。`update_available` 表示版本字符串不同，客户端仍需按项目规则判断是否允许升级或降级。

下载链接可能有有效期，过期后重新检查更新或从项目页获取。不要保存或公开分享含短期签名的下载地址。

## 下载失败排查

确认项目授权、版本是否仍发布、浏览器是否拦截下载，并查看 [Status](https://status.maximoraverse.org/)。免费项目的浏览器下载需要完成页面验证；验证未配置或暂不可用时可能返回 503。网络线路异常时，可尝试项目页的“使用国际源”。

404 可能表示项目不可见、版本已回滚，或没有匹配的平台、架构及灰度版本；403 应先检查账户权限和 Token 状态。提交问题时提供项目名、版本、平台、架构、HTTP 状态码和时间，不要发送 Token 或带签名的下载 URL。
